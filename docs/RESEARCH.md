# Research Notes

MallSphere's feature scope is a synthesized mall-operations prototype, not a claim of industry certification or legal compliance. These public references inform general engineering and security practices:

- OWASP Application Security Verification Standard: https://owasp.org/www-project-application-security-verification-standard/
- GitHub Actions documentation: https://docs.github.com/actions
- MDN Web Docs — Web Storage API: https://developer.mozilla.org/en-US/docs/Web/API/Web_Storage_API
- MDN Web Docs — HTML forms: https://developer.mozilla.org/en-US/docs/Learn/Forms
- MDN Web Docs — Blob: https://developer.mozilla.org/en-US/docs/Web/API/Blob

The current application is a static prototype. Any production implementation should validate domain requirements with actual mall operators and conduct privacy, security, accessibility and operational reviews.
